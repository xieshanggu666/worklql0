# 家庭能源中枢：家庭能源与电费优化系统

模拟家庭一日/一月的用电场景：分时电价、光伏发电、储能电池与可迁移家电负荷联合调度，量化"峰谷套利 + 光伏自用"带来的电费节省。

## 快速开始

```bash
npm install
npm run dev
```

`npm test` 运行测试套件。

## 架构

```
home_energy/
├── engine/
│   ├── tariff.js    分时电价表 + 月度阶梯附加
│   ├── solar.js     光伏逐时出力预测（季节正弦 + 天气衰减）
│   ├── loads.js     基线负荷 + 可迁移家电（含跨午夜窗口）
│   ├── battery.js   储能调度（SOC 离散化动态规划）
│   └── sim.js       场景组装：当日模拟 / 月度账单
├── server.js        HTTP 服务
├── web/             Vue3 + Canvas 前端
└── tests/           引擎测试套件
```

## 核心语义

- **分时电价**：峰（8-11、18-22 点）1.02 元/kWh，平 0.63 元，谷（0-6 点）0.32 元；时段左闭右开。
- **阶梯附加**：月用电超 200 kWh 每度 +0.05 元，超 400 kWh 每度 +0.2 元，按档累计。
- **光伏模型**：出力 ∝ 装机 × 天气系数，日照时长随季节变化，夏季午后达峰。
- **负荷调度**：每个可迁移家电在允许窗口内贪心选择"净购电成本增量最小"的起始时隙；窗口可跨午夜。
- **电池调度**：动态规划在 SOC 网格（21 档）上搜索最小购电成本路径；充电计入效率损耗，放电按电池端功率约束且**只供本地负荷（不向电网反送）**；光伏优先自用、再充电、余电上网。`soc0` 为 0–1 的 SOC 比例。
- **账单**：购电费 − 上网收益 + 阶梯附加。单日返回能量电费（`cost_*`）、当日参考阶梯（`tier_*`）与合计（`bill_*`）；月度账单按确定性伪随机天气序列逐日模拟：
  - 电池末态 SOC 按日**结转**（`daily[i].soc_end === daily[i+1].soc0`），跨日不断档；
  - 阶梯附加为**月度结算项，整月只计算一次**，无储能与含储能按各自整月购电量**分别独立定档**；
  - 逐日推进时把"当前月累计购电量的边际档位加价"（`tariff.marginalSurcharge`）传入当日优化器，避免为谷电套利虚增购电、抬高档位；
  - 日明细与 `/api/simulate` **同源同口径**（同一高精度模拟 + 同一取整投影），给定日边界（天气、`socCarry`、`monthKwhBefore`）可逐字段复现；整月账单 = Σ 日能量电费 + 一次月度阶梯附加，不重复计费。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/system` | 系统信息（可迁移负荷、电价表） |
| POST | `/api/simulate` | 模拟单日（负荷/光伏/电池/逐时电网功率与 SOC） |
| POST | `/api/month` | 月度账单模拟与对比 |
